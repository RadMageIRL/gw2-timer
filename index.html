        Schedule notes

        How sure each time is

          Documented
          At least two independent written sources agree on the time. This is a documentation check, not an in-game check.
          Confirmed in game
          The start was seen in game and matched the schedule within two minutes.
          Disputed
          Sources disagree on the time. Labeled Unverified on the event, with Adjust.
          Unverified
          New or thinly sourced, and not yet checked in game. Labeled Unverified, with Adjust.
          Recheck
          A game update may have changed the time. The previous schedule shows until it is checked.

          Uncertain times

            If you see one of these start at another time, use Adjust on that event to set the time you saw. Your setting stays in this browser.

            GW2 Timer v0.2.1

            A Guild Wars 2 timer for world bosses and meta-events: what is in its scheduled window now, what starts next, in your local time. Unofficial fansite, not affiliated with ArenaNet or NCSOFT.

            Scheduled, not live

            Every time here is a scheduled start. The game publishes no live state for events, so a map can run early, late, fail, or close. "Scheduled now" means the scheduled window is open, not that the fight is on in your map.

            Schedule data

            Most times agree across at least two independent sources. A few carry a label (Schedule notes, at the bottom of the page, lists them):

            • Unverified: new, or the sources disagree. If you see it start at another time, use Adjust on that event to set the time you saw. Your setting stays in this browser.
            • Recheck: a game update may have changed it; the time shown is the previous schedule until it is checked.

            Sources: the Guild Wars 2 Wiki's event timer data, ArenaNet's game update notes and news, and the official Guild Wars 2 API for waypoint codes. Times were also compared with an independent community schedule (qjv/event-timers).

            Privacy

            Settings, stars and adjustments are saved in this browser only. Two things leave it: the clock check asks this site's own address for the time, and the news panel loads headlines from guildwars2.com, so ArenaNet sees that request. You can turn news off.
